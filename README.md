# FAA Airworthiness Directive 2020-24-02 in Akoma Ntoso and LegalRuleML

AD 2020-24-02, the FAA final rule of November 20, 2020, that set the conditions for returning the Boeing 737 MAX to service. It is marked up in Akoma Ntoso XML, with its rules in LegalRuleML, and a CSS stylesheet renders it after the Federal Register page. It was generated by Claude for Grant Vergottini and isn't an official text.

This is an experiment. [The landing page](index.html) reports what fit and what didn't.

## Files

| File | Purpose |
| --- | --- |
| `faa-ad-2020-24-02.xml` | The Akoma Ntoso document, with the LegalRuleML rules embedded |
| `faa-ad-2020-24-02.css` | The stylesheet, linked from the XML |
| `index.html` | Landing page and report |

## About the markup

- **Standard:** Akoma Ntoso 2.0 (AKN 3.1), and LegalRuleML Core 1.0 in the compact form.
- **Validation:** The XML validates against the Akoma Ntoso 2.0 schema. The LegalRuleML was not validated against its schema, which couldn't be loaded here.
- **Text:** The text comes from the Government Publishing Office's plain-text version. A word-by-word comparison with that source found no lost text, apart from the printers' marks listed below.
- **The `adv:` vocabulary:** The predicates under this prefix are illustrative. Its address doesn't resolve to a published vocabulary.

## What's missing or changed

- **Figures:** The ten figures, on 11 images, hold the flight manual procedures and MEL provisions. They are images in the source and aren't transcribed. Each has a placeholder with its page number.
- **Printers' marks left out:** The `BILLING CODE` lines, the `0` markers before amendatory instructions, and the rows of dots in the cost table.
- **Corrected from the plain-text version:** Quote marks and character codes such as `[ecirc]` are converted, and a missing space after one web address is restored.
- **Kept as printed:** The source's own slips, such as "a certain publications" in the DATES section.
